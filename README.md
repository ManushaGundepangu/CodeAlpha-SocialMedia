# ConnectHub - Social Media Platform

A full-stack social media web application developed using Django,
MySQL, HTML, CSS and JavaScript as part of the CodeAlpha Full Stack
Development Internship.

## Features

- User registration and login
- User profiles
- Profile photo upload
- Create posts with images
- Like posts
- Comments
- Follow and unfollow users
- Post deletion by owner
- Like and comment counts
- Responsive and modern UI
- Django admin dashboard

## Tech Stack

Frontend:
- HTML5
- CSS3
- JavaScript

Backend:
- Python
- Django

Database:
- MySQL

## Installation

1. Clone the repository
2. Create a virtual environment
3. Install dependencies
4. Configure environment variables
5. Run migrations
6. Start the Django development server

## Project Structure

The project follows Django's MVT architecture with separate
models, views, templates and static files.
